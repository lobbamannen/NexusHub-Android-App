## Architecture and constraints
Use active NexusHub-Android-App, existing Kotlin native bridge, WorkManager, React themes and navigation. Native shared weather repository/cache is authoritative for page/home/widget; no duplicate JS forecast fetching, no backend or API keys. Weather is phone-only: do not alter watch app or battery night-pause settings. SMHI SNOW1gv1 primary, MET Norway Locationforecast compact fallback; whole forecast run atomically replaced, never mix fields across providers. Preserve prior valid cache on failure and isolate cache by location; validate units/sentinels. Explicit timestamps fetchedAt,referenceTime,point.time. Display missing fields as missing and forecast as forecast. No automatic GPS/background location. API caching, Expires/Last-Modified/conditional requests, bounded responses/timeouts, unique work and debounce; no network inside widget rendering. 2h periodic refresh chosen, no weather quiet hours introduced. MET background fallback only with installed weather widget or foreground app; otherwise keep cache. HTTP429/Retry-After cannot cause immediate retry/failover storms.

Existing SharedPreferences/private atomic file storage is sufficient for one selected location and bounded forecast, no Room dependency. Native geocoding through Open-Meteo's geocoding API on explicit search only, with GeoNames/Open-Meteo attribution; user can alternatively enter coordinates and timezone, without GPS permission. Private noncommercial use. Default exact coordinates verified from geocoder before coding. Source docs and probes recorded separately. Attribution CC BY4.0 and processing disclosed on weather page, accessible by widget tap. User-facing status contains no implementation internals.

## Public bridge/state contract
`weather.getState` -> WeatherState, read only; `weather.refresh` -> queues cache-respecting worker and returns WeatherState; `weather.setLocation` params location -> persisted validated selection and queued refresh; `weather.search` params query -> {places:Location[]}. Native event `weather.changed` prompts local reread. No arbitrary URLs/headers from JS.

Location={name:string,latitude:number,longitude:number,timeZone:string}.
WeatherState={location,provider:'smhi'|'metno'|null,fetchedAt:number|null,referenceTime:number|null,expiresAt:number|null,updating:boolean,status:'empty'|'fresh'|'stale'|'error',error:string|null,current:Point|null,hourly:Point[],daily:Day[],sun:{sunrise:number|null,sunset:number|null,polar:string|null},feelsLike:number|null,feelsLikeMethod:string}.
Point={time:epochMilliseconds,temperature:number|null,wind:number|null,gust:number|null,windDirection:number|null,humidity:number|null,precipitation:number|null,precipitationHours:number|null,probability:number|null,condition:string,isDay:boolean}. condition values clear,partly_cloudy,cloudy,fog,rain,snow,sleet,thunder,unknown. Day={date:'YYYY-MM-DD',min:number|null,max:number|null,condition:string,partial:boolean}. `current` means closest usable forecast time, not an observation. No future forecast rebranded as live measurement. Daily values are sampled forecast min/max and may be partial.
