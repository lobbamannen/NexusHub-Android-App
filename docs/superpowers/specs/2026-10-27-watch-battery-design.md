# NexusHub Two Thumbs Battery

Authorized by Robin after read-only research and discussion. Extend the active Android repository; no changes to Databas. Kotlin/RemoteViews two-row scalable widget for phone and Watch8 Classic, black/transparent background and gold accents. Minimal Wear OS companion, same installed applicationId and release certificate. DataClient latest state, MessageClient explicit refresh, CapabilityClient discovery. Local persistent snapshots independent of WebView. Scheduled background sampling with truthful timestamps; no real-time promise, no permanent foreground service.

Reuse the existing opt-in PostHog EU project 280222. Battery telemetry is a native-only allowlist, exact percentages and generated per-measurement UUIDs; no MAC/node IDs, device names, tokens or user content. Watch stores a bounded local technical journal, forwarded by the phone only for entries produced during its current enabled consent epoch. Widget render events mean accepted Android update, not visible LockStar proof. No PostHog SDK on watch.

Alternatives considered: hidden Samsung API/Bluetooth reflection rejected as production dependency; direct BLE remains unverified and unnecessary because Robin accepts a watch app. React/WebView is not the widget host.

Physical installation/LockStar/Doze and power tests remain user-device checks. Build and publish both signed APKs with existing stable identity, preserve existing phone data, document installation.
